# Implementación y verificación · INGEBAM Ventanas3D

Configurador visual independiente de ventanas. `index.html` incluye interfaz, lógica de cotización, generación de resumen y exportación JSON.

## Ejecución
Puede servirse mediante cualquier servidor estático; por ejemplo, desde la carpeta del repositorio: `python -m http.server 8000`, luego `http://localhost:8000/`.

En caso de tener GitHub Pages activado: https://man-nuel-b.github.io/INGEBAM-Ventanas3D/

## Pruebas recomendadas
1. Cambiar tipo de ventana, dimensiones, terminación y tipo de vidrio.
2. Confirmar que el dibujo y la estimación responden a todos los cambios.
3. Probar copiado de cotización, impresión/PDF desde el navegador y descarga JSON.
4. Revisar dimensiones extremas, orientación vertical/horizontal y controles móviles.
5. Validar tablas de precios y coeficientes con proveedores antes de comercializar.

La cotización de demostración no sustituye una evaluación técnica ni constituye oferta vinculante. Este proyecto no modifica Inmo3D, Muebles360, Cubikeitor ni TIMELESS TCO.
